## Non-negotiable visual language

- Premium **architectural/editorial modernism**, not generic SaaS and not an unrelated sci-fi theme.
- Graphite and deep charcoal surfaces, copper/bronze architectural forms, warm ivory type, subtle layering and disciplined contrast.
- Starting tokens (refine using observed contrast): `#0B0D11` base; `#13161B` secondary; `#1D2026` elevated; `#F1ECE5` body; `#AAADB5` muted; `#D3A379` copper accent. Copper must not encode success/failure on its own.
- Original or rights-cleared architecture imagery; editorial display serif for heroes, highly legible interface sans, monospace code. Build all text and interactions from accessible DOM components rather than rasterizing the design board.
- Tight but breathable 3-region Studio layout: left nav, project workspace, optional right context inspector. Signature Room integrates discussion, decisions, evidence and source context. Public Discover is cinematic and immediately comprehensible; Client Space is calmer and plain-language.
- Consistent 1440+ desktop, 768/1024 tablet and 320/390 mobile behavior; no horizontal scrolling, semantic interactive states, keyboard access, responsive type, reduced motion and WCAG 2.2 AA target.
- Validate each screen with screenshot comparisons to the primary board and **real task flows**. Prioritize working project creation, persistent Room notes/decisions and genuine authorization over feature theater or decorative metrics.
